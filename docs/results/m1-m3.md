## M2: baselines and throughput

Evaluation on three SHA-256-derived validation seeds with 150 events/episode and `exploration_v1` reward (all zero natural completions): random mean reward 2.3267, heuristic 4.73, untrained Q 1.15. These are descriptive values. The heuristic moves through known cells and seeks frontiers but can loop or hit no-progress truncation; it is not a strong game baseline.

Random-agent benchmark, four episodes and 600 events per setting: an initial 1-worker run measured 229.3 events/s in 2.617 s; 2 workers measured 622.8 events/s in 0.963 s. Reverse order measured 343.4 and 600.2 events/s. After sampled child RSS collection, a 1-worker run measured 171.6 events/s in 3.496 s and 2 workers measured 419.5 events/s in 1.430 s. Per-child sampled RSS was about 5.4–5.6 MiB, sampled every 16 events, so peaks may be missed. The first pair's `/usr/bin/time` parent peaks were 22,492 and 23,480 KiB. WSL cache and instrumentation changed between runs; no linear scaling conclusion follows. Events include menu inputs and are not game turns.

Representative SQLite run IDs: random evaluation `a7e72c21-e400-4908-9cc6-1b4d51b1a20a`, heuristic `dc10cffc-1f86-4c88-9c00-9ab6b7b6c191`, untrained Q `b449e937-ba4e-4712-8fd7-bb8fd477eafc`, 1-worker sampled-RSS benchmark `aaf53d14-f930-4fe1-95ad-e3c3e04ac727`, 2-worker sampled-RSS benchmark `c85b5637-e3e4-4180-8ae6-4fe81fea114c`.

## M3: actual learning

The first tabular Q run trained for four real Brogue episodes, with 531 Q updates, 460 changed updates and 20 encoded states. A second bounded run with periodic validation and inference checkpoint (`12429015-dafb-4274-8865-72fbb77f15b6`) repeated those totals in 3.297 s. Validation used one episode per checkpoint: mean shaped reward 0.72 after episode 2, 0.01 after episode 4. These single samples cannot select a statistically reliable best model. The inference checkpoint was loaded for a separate three-seed evaluation: mean reward 0.5233, zero natural completions. Resume to six total episodes (`40974757-b3a8-4f95-8bd0-a980fab11fe0`) yielded 737 cumulative updates, 551 changed updates and 40 encoded states. Separate three-seed evaluation after resume gave mean reward 1.4133, zero natural completions. The untrained Q mean on the same seed protocol was 1.15. There is no demonstrated improvement in game competence or win rate. Checkpoint hashes were unchanged by evaluation.

The pipeline can update, checkpoint, load, resume and evaluate on real Brogue. It is **TRAINING_PIPELINE_READY for the narrow exploration task**, not **FULL_GAME_TRAINING_READY** or **SPECIALIST_AGENT**. M1 and M2 remain partial against the broader gates: contextual commands and targeting need coverage, the observation audit is incomplete, the heuristic is weak, and a live victory has not been demonstrated.

Accounting correction: the initially visible cells and starting depth were incorrectly included in `reward_components` totals on reset even though no corresponding step reward was returned. This was corrected after the exploratory runs above. Their reported `reward` fields and Q updates were unaffected; their component breakdowns should not be used for analysis. New runs are required for component-level conclusions.

After the fix, a fresh four-episode run `d3488580-0a09-48bb-a35f-1a5212881bb4` again made 531 updates and 460 changed updates in 8.005 s. Its inference checkpoint SHA-256 was `894e9653638bcf6bb8b8d35ce48be952de73103d0fc160b0673ca7826bf8b924`. A separate three-seed validation run `60622890-5091-4bbd-8648-78853c27f786` loaded that checkpoint, recorded mean shaped reward 0.5233, zero eligible completions, 450 events and 110.1 wall events/s. This confirms the corrected pipeline runs; it does not establish improved policy quality.
