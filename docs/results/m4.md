# M4 results — 2026-10-30

## Objective and method

Question: can Maia learn a player-legitimate exploration behavior in real Brogue CE and improve on unseen seeds? The [frozen task protocol](../experiments/m4-exploration.md) specifies Classic/Normal, 120 input events, 8 seconds, one worker, raw new-cell count as primary metric, and 16 shared final seeds. Two independent 30-episode CPU training runs used master seeds 20261031 and 20261032. No final-seed result was used to change weights or hyperparameters. A later fixed-north control used a different validation master, 20261033, and is explicitly post-hoc.

## Integrity and engineering

EXP-0014: inventory display/cancel consumes zero turns; remove/re-equip starter dagger takes one turn each; food application requires three input events and one turn. A raw event step remains canonical. EXP-0015: source review found `getLocationFlags(..., true)` uses remembered flags for discovered nonvisible terrain. The adapter filters entities by player perception and the gameplay action list is seed-independent. Tests cover visible-entity coordinates, different seed masks and starter inventory. Secret terrain, magical detection, hallucination and all target/item flows still need differential audits. Real death and quit tests remain green; callback-only victory fixture remains distinct from a live victory.

The optional movement-only Gymnasium 1.2.2 wrapper passed `check_env()`. Its first run failed the deterministic-info check because sampled RSS varied; it now excludes scheduling-dependent samples from Gym `info`. The validator warns that alternative render modes were not tested because the wrapper lacks a registered `spec`. The raw environment remains a separate event-step API. AddressSanitizer and UndefinedBehaviorSanitizer built and passed a real seed-123 death probe at 80 events; this does not prove absence of all native memory defects.

EXP-0016: the old tabular encoder merges strategically different map positions. The new linear policy uses 16 action features and within-episode visits. A five-seed diagnostic after training A selected north (`k`) 234/321 times and had 60 stalled moves versus 150 for the zero-weight initial policy. This suggested a directional shortcut, prompting the separate control below. EXP-0018: the initial policy averaged 159.2 new cells on five validation seeds, but had early no-progress truncation.

This does not imply strong navigation, survival, wins, or full-game readiness. The manual heuristic remains far ahead.

### Post-hoc directional control

On a separate 16-seed validation set (master 20261033), always moving north averaged 179.5 new cells. Trained A averaged 259.4 (+79.9 paired, bootstrap [19.4, 154.7]) and B 257.6 (+78.1, [24.4, 146.3]). Each tied fixed north on roughly half the seeds and improved on the rest. The learned policies strongly favor north but also change action when it stalls. This diagnostic was designed after inspecting the final result and is not a new confirmatory test.

## CPU and system cost — EXP-0021

Equivalent random-agent workload: five episodes, 534 input events, 516 gameplay decisions, 418 game turns, same five seeds, same binary SHA-256 `70ecb2d30a6896ad3cba9d6329ad4ad2559fa78ae29c90b940f89d1f455874ec`. With the binary on `/mnt/c`, two later one-worker measurements took 4.075 and 3.890 s; reset alone used 3.323 and 3.206 s. With the same binary on the Linux filesystem, one-worker runs took 0.755 and 0.920 s (707 and 580 events/s), reset 0.122 and 0.129 s. Two-worker Linux runs took 0.746 and 1.132 s wall (716 and 472 events/s). A prior first mounted run was started by a command harness that failed to poll its returned session; no completed record was collected, so it is excluded as a measurement error. Filesystem location dominates this short workload; two workers did not consistently beat one. Sampled child RSS was about 5.6–6.0 MiB. Python policy time for random was roughly 0.002–0.003 s over the workload; `step_s` includes engine, IPC and JSON parsing, so serialization alone was not isolated. Five trained-A diagnostic episodes took 3.94 s on `/mnt/c`, with 3.41 s reset, 0.065 s policy inference and 0.457 s steps. Training A and B above include simulation, inference and updates. No GPU was used.

## Remaining limits

The trained agent only moves. It cannot finish a Brogue campaign through the current skill API. The observation audit is incomplete for special perception and unidentified items; targeting, device use and a live victory replay are unresolved. The 16-seed interval is preliminary, not evidence of broad generalization. A fixed-direction prior accounts for some improvement. Raw SQLite and checkpoints remain ignored in `data/`; their run IDs and checkpoint hashes above are an artifact manifest for this local result. The historical upstream seed-catalog comparator still fails on the Windows checkout; the strict normalized-body comparator from M1–M3 remains the supported check.
