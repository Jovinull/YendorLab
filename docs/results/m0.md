# M0 result — 2026-10-30

## Objective and method

Prove a bounded Python agent can act in real Brogue CE without graphics. The native code is official CE v1.15.1, commit `1ba4240b7a928ddf0ffb772717bf1d433cd63804`, plus [patch](../../native/patches/0001-yendorlab-stream.patch), SHA-256 `dc52682a7b1f7d314edc0ba97cc92d4de895e1b1cbde77581a20b6d0f20c6a1a`. WSL2 Ubuntu on an i5-1335U; one worker; Normal Classic; eight-direction uniform random policy. Each episode is a fresh process. Python and pipe overhead are included in timing. Data files and SQLite run records are in ignored `data/`.

This is not per-child peak RSS or a full machine memory profile. The action rate is end-to-end **input callback** throughput, not pure engine simulation or useful game turns/s. ## Validation and failure

- `make -j2 GRAPHICS=NO TERMINAL=NO RELEASE=YES bin/brogue`: passed in WSL. Upstream warnings occurred in `Buttons.c` and `platformdependent.c`.
- `PYTHONPATH=src python3 -m unittest discover -s tests -v`: 4 tests passed, including same-seed observation hashes and restricted observation keys.
- Upstream `test/compare_seed_catalog.py` on its Classic 25-seed, 40-level fixture: **failed**. Diagnosis: the checked out fixture has Windows CRLF while generated output has LF; its header also names CE 1.13 development. The complete catalog body after the four-line header matches byte for byte after line-ending normalization (`cmp` exit 0). This is evidence against a generator difference for these seeds, but the official test remains red in this checkout.
- Upstream recording regression runner had no `.broguerec` fixtures in the repository and was not run.

## Interpretation, limits, next step

The direct adapter proved programmatic headless action and observation of real game state, plus fresh-process resets. Same-build replay held for one seed/policy over 100 actions. Cross-platform determinism, information equivalence to the human UI, natural terminal results, full action legality, menu navigation, and game outcomes remain unproven. Next build a context-aware decision boundary and visibility-audited terrain/inventory observation, then measure useful game turns/s and obtain completed episodes before training Maia.
