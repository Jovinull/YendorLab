# ADR 0003: Event steps and a linear exploration skill

Status: provisional, 2026-10-30. Extends [ADR 0002](0002-learning-pipeline.md). Amended by [ADR 0004](0004-m5-benchmark.md), which replaces the task and encoder.

The native one-event `step` remains the canonical audit interface. A logical action could combine item selection, confirmation and target input, but it would need to pause when new player-visible information changes the choice. The present event contract is slower and exposes more bookkeeping, but preserves exact turn and prompt accounting. An optional Gymnasium adapter combines only movement with deterministic, safe prompt acknowledgments for the bounded exploration task; it reports native event and game-turn deltas. It does not replace the raw protocol or claim a complete action API.

The v1 tabular Q state encodes local blocked/unknown cells, HP and visible threat, but omits location, frontier direction and visit memory. Distinct exploration situations collide, and equal-looking walls at different locations share values. We kept v1 checkpoints loadable under their original encoder version. The new feature version 2 computes eight action-specific vectors, each with 16 bounded values: bias, adjacent unknown, known blockage, visible creature, visit count, route to a known frontier, immediate reverse, currently visible target, and eight direction indicators. It uses only the protocol's filtered map and within-episode history. A single 16-weight linear action-value function with TD updates generalizes across seeds at low CPU cost. Checkpoints reject other encoder versions.

Alternatives: improved tabular Q would still need many combinatorial states; a compact neural model adds dependencies without evidence of need; evolution requires many complete rollouts for each candidate; PPO is disproportionate for this first short task; a planner is a useful manual baseline but does not demonstrate learning. The learned policy uses movement only. Reward is `10 × new-cell component of exploration_v1 + terminal component`; raw new-cell count is the independent evaluation target. Natural terminal states have no TD bootstrap. Valid action/no-progress truncation bootstraps from the returned gameplay observation; timeout, engine and protocol failures have no verified next state and do not update the final transition.

The two 30-episode pilots altered all 16 weights and improved raw new-cell count over their zero-weight initial policy on the frozen 16-seed final set. Both still trail the manual heuristic considerably. Post-hoc controls show a strong northward directional bias; a fixed-north agent explains part, but not all, of the observed gain on separate diagnostic seeds. We classify this as narrow learned exploration behavior, not broad navigation competence. Special perception, item actions and full-game victory remain outside the validated skill contract.
